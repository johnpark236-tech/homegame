# Korean Animal Race — 4-player MVP

외국인 한국어 학습자를 위한 QR 기반 실시간 팀 레이스 웹게임입니다.

## 바로 실행

- 공개 주소: https://johnpark236-tech.github.io/homegame/
- 교사: `방 만들기` → QR 표시 → 학생 입장 확인 → `GAME START`
- 학생: QR 스캔 → 닉네임 → 팀 선택 → READY
- 정답자는 3초 동안 화면을 빠르게 TAP
- 같은 팀의 TAP이 합산되어 캐릭터가 100m 전진

## MVP 구성

- 최대 4명
- 2팀 × 2명
- 용 팀 / 호랑이 팀
- 10개 초급 한국어 문제
- 8.5초 문제 풀이 + 정답자 3초 TAP
- 실시간 팀 TAP 합산
- 100m 거리 계산 및 승리 판정
- 방장 재경기

## 기술 구조

정적 GitHub Pages + PeerJS(WebRTC) 방식입니다. 별도 Firebase/Supabase 계정 없이 방장 브라우저가 실시간 게임 호스트 역할을 합니다.

- `index.html`: 화면 구조
- `styles.css`: 모바일/교사용 반응형 UI 및 달리기 애니메이션
- `app.js`: 방 생성, QR, 팀 입장, 퀴즈, TAP, 실시간 동기화, 승리 판정

외부 런타임 라이브러리:

- PeerJS 1.5.5 — 실시간 브라우저 연결
- QRCode.js 1.0.0 — 참가 QR 생성

## 수업 테스트 권장 절차

1. 교사 PC에서 사이트 접속
2. 방 만들기
3. 스마트폰 4대로 QR 스캔
4. 용 팀 2명 / 호랑이 팀 2명 배정
5. GAME START
6. 학생들이 문제에 답함
7. 정답자만 3초 TAP
8. 팀 캐릭터 이동 확인
9. 골인/결과 확인
10. 다시하기

## 개발 테스트

주소 끝에 `?debug=true`를 붙이면 하단에 간단한 연결 로그가 표시됩니다.

예: `https://johnpark236-tech.github.io/homegame/?debug=true`

## 현재 MVP 제약

- 방장 페이지를 닫으면 방도 종료됩니다.
- PeerJS 공개 시그널링 서비스에 네트워크가 연결되어 있어야 합니다.
- 학생 새로고침 시 재입장이 필요합니다.
- MVP 레이스는 용/호랑이 2팀이며, 곰/사자 캐릭터는 다음 4팀 확장 단계에서 활성화할 예정입니다.
